# Yavan

## Le Shem

(*Yavan* / יָוָן) est le nom hébreu de ==la Grèce== — plus exactement des Ioniens, les Grecs d'Asie Mineure que le Proche-Orient rencontrait le premier. Le mot et *Iônia* sont le même nom.

Il est fils de [[Yaphet]], dans la table des nations.

## Ce que ce nom fait dans l'ONT

Il faut le dire franchement, parce que ce **Shem** touche ==la raison d'être du projet==.

[[Noach]] formule sur [[Yaphet]] une dotation qui joue de son nom : ==qu'**Elohim** l'élargisse==, *yaft*. Le texte dote — et le corpus relève ce que l'histoire en a fait.

L'élargissement de [[Yaphet]], accompli dans la lignée de ==Yavan==, ==deviendra le filtre hellénistique qui absorbe l'ontologie hébraïque au lieu de l'habiter==. Ce qui devait s'étendre pour servir la structure de [[Shem-fils-de-Noach]] est venu ==la recouvrir==.

## Le recouvrement que l'ONT existe pour défaire

C'est exactement ce que le §1 pose comme critère : un texte entre dans le corpus s'il pense en hébreu, il en sort s'il a absorbé ==des catégories helléniques==, fût-il d'auteur juif.

Le nom de ==Yavan== est donc, dans ce corpus, ==le nom de ce qu'il faut découvrir==. Non pas un ennemi : un ==recouvrement==. La différence compte — l'ONT n'écarte pas la Grèce par hostilité, il écarte une grille de lecture qui empêche de voir ce que le texte hébreu dit.

Et le corpus tient les deux faits ensemble sans les concilier : ==la dotation était bonne, et l'histoire l'a retournée==. Il ne dit pas que [[Noach]] s'est trompé.
